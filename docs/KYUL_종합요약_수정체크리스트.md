> 진척 40~70%는 감점 요인이 **아닙니다**. 다른 팀도 미완성입니다.

### ③ 무기를 안 꺼냈고, 지면을 거꾸로 썼다

- **기저선 갭** — 다른 팀에 없고 무료 LLM도 구조적으로 못 하는 각도인데, 제목·요약본·1페이지 어디에도 없음. 랜딩 카피 "기저선과 면접의 갭으로 나도 모르는 나의 결을"이 서류 최고의 문장인데 **캡처 이미지 안에만** 있음

## 5. 요약본 첫 문장 교체 (가장 저렴하고 효과 큼)

**현재**
> 구직자의 음성 데이터 분석과 RAG 기술을 결합하여 성향 파악부터 직무 심층 면접까지 수행하는 종합 AI 면접 솔루션이다.

**교체안**
> **면접장의 나는 평소의 나와 얼마나 다른가.**
> 결(KYUL)은 편안한 일상 대화에서 개인의 **기저선(Baseline)** 을 먼저 측정하고, 동일 지표를 압박 면접에서 다시 측정해 **그 변화량(Gap)** 을 보여주는 면접 연습 도구다. 기존 AI 면접이 "당신은 이런 사람"이라는 절대 평가를 내린다면, 결은 **같은 사람의 두 상태를 비교**한다. 개인 내 비교이므로 타인과의 대조 없이 성립하며, 사용자의 평상시 데이터를 갖지 못하는 범용 대화형 AI가 구조적으로 제공할 수 없는 정보다.

**개발보고서 1페이지 순서도 교체**

```
현재: 프로젝트 정의 → 기획 의도 → 시장 표 → 개발 배경 → 특·장점 4개 나열

교체: ① 기저선 갭 한 문장 + 개념도
      ② 왜 필요한가 (자기기입식 검사의 한계 + 문헌 1~2편)
      ③ 실제로 재본 결과 (파일럿 그래프)
      ④ 어떻게 구현했나 (성숙도 표 + 아키텍처)
      ⑤ 어디에 쓰이나 (공익 프레임)
```

→ 수상 팀들이 공통으로 갖췄다는 **문제 → 대상 → 해결 → 검증 → 효과** 흐름과 정확히 대응.

## 7. 프론트엔드 수정 (보고서에 실릴 캡처 기준)

### 🔴 반드시 — 반나절

- [ ] **레이더 차트 축 `aa~ff` → 실제 역량명** (회복탄력성/가치정합성/적극적소통/성취지향성/협력·배려/자기객관화)
      → 지금 상태는 심사위원에게 "아직 목업"으로 읽힘. 클라이맥스 화면에서 가장 큰 손해
- [ ] **랜딩 "6가지 결" 캡션의 내부 개발 메모 삭제**
      → *"MVP에서는 규칙 기반 점수와 참고용 멀티모달 스텁으로만 채웁니다"* 가 사용자 화면에 노출된 채 제출됨
- [ ] **컬처핏 "(데모 데이터)" 표기 제거** or 화면 삭제

### 🟠 권장

- [ ] **결과 프레이밍 전환**
      `일치율 57.8% [High Risk(위험)]` → `평소와의 일치도 57.8% / 가장 크게 변한 지표: 적극적 소통 [집중 연습 권장]`
      등급도 `위험·주의` → `안정 / 관찰 / 집중연습`
      ※ 자신감 회복이 목적인 서비스가 "위험" 딱지를 붙이는 건 기획-UI 불일치로 지적당하기 좋음
- [ ] **리포트 정보 위계 정리** — 1스크린: 중첩 레이더 + 한 줄 진단 + 변화 큰 지표 3개 / 2스크린: 상세+근거 / 3스크린: 다음 액션
- [ ] **점수 옆에 근거 노출**
      ```
      적극적 소통  62점  ▼ −35.0
        └ 시선 이탈 18% → 41%  ·  발화 속도 3.2 → 4.6 음절/초
        └ "어… 그러니까" 반복 7회
      ```
      → 설명가능성 확보 + "이 점수 어디서 나왔나" 질문 사전 차단

### 🟡 여유 있으면

- [ ] 자가분석 → 가상면접 → 리포트 상단 **진행 스테퍼** (캡처만 봐도 3단 루프 전달)
- [ ] 가상면접 지표 바에 **"내 평소 수준" 기준선 마커** ← 구현 대비 서류 효과 최대
- [ ] 대시보드 캡처의 더미값(100 / 9.0 / 9.0) → 파일럿 실제 데이터로 교체
