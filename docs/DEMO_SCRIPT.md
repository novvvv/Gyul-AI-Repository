# 시연 영상 대본 — 결(結)

> **총 6분 내외** · 진행자 멘트 · 화면 동작 · 답변 대사 전부 포함
> AI 질문은 코드에 고정돼 있습니다 → [`questions.ts`](../frontend-next/src/lib/questions.ts)
>
> **[멘트]** = 진행자가 읽을 말 · **[화면]** = 그때 할 조작 · **[답변]** = 마이크에 대고 말할 대사

---

## 촬영 전 점검

| 항목 | 확인 |
|---|---|
| 브라우저 | **Chrome 또는 Edge** — Firefox·Safari는 음성 인식이 안 됩니다 |
| 주소 | `http://localhost:5174` |
| 서버 | 상단 상태 표시가 「연결됨」인지 확인 |
| 마이크·카메라 | 권한 허용. 얼굴이 화면 중앙에 오도록 |
| 소음 | 에어컨·키보드 소리 차단 |

**말하기 규칙 세 가지**

1. **문장을 끝내고 쉰다.** 침묵 0.7초가 감지되면 그 발화가 확정됩니다. 문장 중간에 쉬면 두 개로 잘립니다.
2. **자가분석은 감정을 담아, 면접은 정돈해서.** 이 차이가 리포트의 내용이 됩니다.
3. 잘못 말했으면 **그냥 다시 말하면 됩니다.** 마지막 발화가 답변으로 기록됩니다.
