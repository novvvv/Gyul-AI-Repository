# Eyedia 벤치마크 요약 — KYUL이 가져갈 것

> 2025 한이음 금상. KYUL과 기술 스택이 가장 가까운 사례(시선추적 + RAG + LLM)라 비교 가치가 큼.
> ※ 보고서 원문은 비공개. 아래 「사실」은 언론 보도 확인분, 나머지는 추론.

---

## 1. 사실

| 항목 | 내용 |
|---|---|
| 팀 / 작품 | 무물매니저(덕성여대) / **Eyedia** — 스마트 아이웨어 AI 도슨트 |
| 수상 | **금상** (2025) |
| 기술 | 시선·작품 추적 카메라 + RAG 지식 검색 + LLM 해설 생성 |
| 기능 | 관람객 시선으로 작품 특정 → 맞춤 해설, 작품 스크랩 |

2025 시상: 대상 3 / **금상 7** / 은상 14 / 동상 16 / 장려상 85 (총 125팀)

---

## 2. 핵심 차이 — 한 줄

```
Eyedia :  시선추적 → "어느 작품인지" 특정 → RAG 검색 → 해설
KYUL   :  시선추적 → 41% → 62점 → −35pt → High Risk
```

Eyedia는 중간 결과가 **이름 있는 대상(작품)** → 틀리면 즉시 들통남 → 숨을 곳 없음 → **그 자체가 신뢰의 근거**
KYUL은 **숫자로 끝남** → 3단계 추상화, 각 단계 근거 없음 → 맞는지 틀린지 확인 불가

> **점수는 틀릴 수 없고, 틀릴 수 없는 건 맞을 수도 없다.**
> 심사위원이 검증할 수 없는 출력은 주장으로 분류된다.

**기술력 차이가 아니라 "검증 가능하게 설계했는가"의 차이.**

---

## 3. 비교표

| 축 | Eyedia (금상) | KYUL |
|---|---|---|
| 시선추적 출력 | 작품 ID (이름 있음) | 시선이탈률 % |
| 검증 가능? | 즉시 가능 | 불가능 |
| RAG 지식베이스 | 미술관 도록 (외부 실재, 출처 명확) | 사용자가 붙여넣은 JD·자소서 |
| 실패의 가시성 | 숨을 곳 없음 | 드러나지 않음 |
| 하드웨어 | 스마트 아이웨어 | 없음 (순수 웹) |
| 데모 | 쓰고 걸어다니면 끝 | 화면 캡처 나열 |
| 프레임 | 도슨트 접근성 (공익) | B2B SaaS 확장 |

---

## 4. 6일 안에 할 것 2개

### ① 점수 옆에 "관찰 기록" 붙이기 — Eyedia의 '작품 ID' 자리

```
Q3. "실패했던 경험을 말씀해 주세요"        (0:00~1:24)
  0:08   시선 이탈 시작 — 12초
  0:31   발화 속도  3.2 → 5.1 음절/초
  0:47   무음 3.4초
  1:02   "어… 그러니까" 4회 연속
  ─────────────────────────────────
  평소 대비: 시선이탈 18%→41%, 발화속도 +59%
```

점수가 아니라 **사건**. 알고리즘이 무엇이든 이 형태로 제시되면 **검증 가능한 산출물**이 된다.
사용자에게도 "62점"보다 유용 → 행동으로 이어짐.

### ② 기저선 재현성(test-retest) 측정 — 서비스의 존재 증명

같은 사람이 **다른 날 자가분석 2회** → 6대 역량 점수 상관 확인.
기저선이 재현되지 않으면 갭 분석 전체가 무의미. 반대로 상관이 나오면
**"우리 기저선은 재현된다"** 한 문장 확보 — 서류의 어떤 주장보다 무겁다.

- 비용: 파일럿 15명 중 **5명만 이틀에 걸쳐 2회** (+1시간)
- ⚠ 선행 조건: 점수식의 **랜덤 노이즈 ±3pt 제거** (안 그러면 측정 불가)

## 5. 덤 2가지

**RAG 지식베이스를 실제 채용공고 코퍼스로**
Eyedia가 미술관 도록을 가진 자리에 KYUL은 **채용공고**를 놓으면 된다.
→ 부수 효과: 기업 인재상이 채용공고에 실제로 적혀 있으므로, 현재 "(데모 데이터)"로 표기된 **컬처핏 문제도 함께 해결**.

**같은 해 금상 온음(ON-UM)에서 배울 프레이밍**
기술은 통화 음성 실시간 분석 — KYUL의 SER과 같은 영역. 그런데 팔린 건 **"감정노동자를 지킨다"**.

| 현재 | 번역 |
|---|---|
| "구직자 성향을 객관적으로 진단" | "면접 컨설팅비를 감당 못 하는 청년도 반복 훈련할 수 있게" |
| "B2B SaaS·기업 HR 확장" | "대학 취업지원센터 연계 / 비수도권 기회 격차 완화" |

같은 제품, 다른 문장. 2025 수상팀 후기에도 평가자가 *"수익보다 문제 해결"*, *"사회적 공헌도"* 를 선호했다는 서술 있음.

## 6. 현실적 목표

```
대상 3    ← 전부 하드웨어(요리로봇/스마트디바이스/센서빗). 순수 웹은 구조적으로 어려움
금상 7    ← Eyedia 위치
──────────────────────────────
은상 14 / 동상 16   ← ★ KYUL 목표 구간 (상위 32팀)
──────────────────────────────
장려상 85 ← 참가 상위권이면 대체로 도달
```

동상 이상 진입 = 위 4가지 중 **최소 2개**. 6일이면 ①+② 가능.

---

## 7. 결론

KYUL의 기저선 갭 아이디어는 Eyedia의 시선-작품 매칭보다 **오히려 독창적**이다.
문제는 그 독창성이 **검증 불가능한 형태로 포장**되어, 심사위원이 좋다/나쁘다를 판단할 수조차 없다는 것.

**판단할 수 없으면 점수를 줄 수 없다. 검증 가능하게 만드는 것이 6일 작업의 전부.**
